# 音云 Windows 客户端

<img src="assets/icon.png" alt="音云" width="96" height="96">

音云 Windows 客户端是一款连接[音云服务器](https://github.com/bobcc4/yinyun-lxserver)使用的桌面音乐播放器。它拥有独立的播放器界面，不嵌入服务端网页，也不会在 Windows 本机运行第二套服务端。

## 客户端功能

- 搜索 TX、WY、KW、KG、MG 平台音乐。
- 浏览 TX、WY、KW、KG 平台排行榜并直接播放榜单歌曲。
- 播放、暂停、上一首、下一首、进度、音量与循环模式。
- 播放队列、队列恢复和歌词显示。
- 将歌曲直接下载到 Windows 本地目录，不进入服务端下载队列或服务端缓存。
- 收藏或取消收藏歌曲、歌手和专辑。
- 创建、重命名和删除歌单，将歌曲加入歌单或从歌单移除。
- 选择播放音质，无法满足时由服务端执行音质和平台回退。
- 数据同步中心定期保存加密快照，可备份或恢复歌单、设置和自有音源。
- 托盘常驻、开机启动和客户端自动更新检查。

客户端不提供服务端后台管理、服务端下载、本地文件管理、缓存管理或歌曲洗版。这些操作应在音云服务端网页中完成。

## 下载与安装

在 [Releases](https://github.com/bobcc4/yinyun-windows/releases) 下载对应安装包：

- Intel/AMD Windows 设备使用 `x64-Setup.exe` 或 `x64-Portable.exe`。
- Windows on ARM 设备使用 `arm64-Setup.exe` 或 `arm64-Portable.exe`。
- 支持 Windows 10 和 Windows 11，不支持 Windows 7 与 ARMv7。

## 连接服务器

首次启动填写：

- 音云服务器根地址，例如 `http://192.168.1.10:9527`。
- 音云同步账户用户名。
- 音云同步账户密码。

地址不要添加 `/music` 或 `/rest`。登录凭据由 Windows 安全存储加密保存，播放器页面不会读取账户密码。

## 收藏与歌单

客户端的收藏和歌单以服务端账户数据为准：

- “我的收藏”对应当前账户的收藏歌单。
- 收藏歌手和收藏专辑保存在当前服务端账户中。
- 自建歌单会在 Windows 客户端、网页播放器和兼容客户端之间同步。
- 搜索结果可以直接收藏、播放或加入自建歌单。
- 客户端退出或重启后会恢复上次播放队列，但不会自动开始播放。

## 数据同步与恢复

客户端每 30 秒检查一次服务端同步数据变化，并使用 Windows 安全存储加密保存本地快照。快照包含：

- 试听列表、我的收藏和自建歌单。
- 收藏歌手和收藏专辑。
- 用户设置与音效配置。
- 当前用户拥有的自定义音源脚本及平台选择。
- 不喜欢规则。

如果服务器容器和全部持久化目录被删除：

1. 重新部署支持账户同步恢复的音云服务器。
2. 重新创建与原账户相同的小写用户名，可以设置新密码。
3. 在 Windows 客户端使用该账户登录。
4. 客户端检测到服务端为空后，选择“恢复并打开”。

恢复不会还原已经删除的音乐文件、缓存文件、下载任务、待处理歌单分享邀请、音源分享关系或其他用户拥有的共享音源偏好。自定义音源恢复后默认禁用，需要用户检查后重新开启。

同步中心还支持导出和导入 `.json` 备份。手工导出文件不使用 Windows 设备加密，应妥善保管。

## 服务端要求

服务端需要提供带版本号的 `/api/v1` 接口，包括账户登录、搜索、排行榜、收藏歌手和专辑、播放地址解析、歌词、歌单和同步快照能力。反向代理需要放行 `/api/v1` 和实际音频地址，并支持音频 Range 请求；第三方认证不能拦截这些接口。

## 本地开发

需要 Node.js 22.12.0 或更高版本，推荐 Node.js 24 LTS。

```bash
npm install
npm start
```

运行测试和构建：

```bash
npm test
npm run dist
```
